# 🤖 Telegram AI Autoposter (Telethon + Aiogram 3 + AI)

Автоматизированная система ведения Telegram-канала с ИИ-редактором, парсингом **открытых и закрытых** каналов, склейкой медиа-альбомов и интерактивной **предложкой в боте**.

---

## ✨ Возможности

* **Чтение любых каналов-доноров:** открытые (`@username`, `t.me/...`) и закрытые по инвайт-ссылкам (`https://t.me/+...`). Юзербот сам вступает в них прямо по команде из вашего бота.
* **Полная поддержка медиа:** перехватывает фото, видео и **медиа-альбомы** (2–10 файлов склеиваются в один пост). В предложке есть кнопка `🖼 Убрать медиа`, если вы хотите опубликовать только текст.
* **Умный ИИ-редактор:**
  * Переписывает посты живым языком в стиле вашего канала.
  * Вырезает чужие `@юзернеймы`, ссылки `t.me/...` и призывы подписаться (двойная защита: ИИ + регулярные выражения).
  * Отсеивает рекламу, казино, прогревы и **смысловые дубли** новостей.
  * Поддерживает **Google Gemini** (бесплатный тариф), **OpenAI**, **OpenRouter**, **DeepSeek**, **Groq** и локальные модели.
* **Интерактивная предложка (в ЛС бота):**
  * `✅ Опубликовать в канал` — мгновенная публикация в ваш канал.
  * `🔄 Переписать (ИИ)` — перегенерация поста (можно написать комментарий ИИ, например: *«сделай короче и дерзко»*).
  * `✏️ Свой текст` — ручная правка текста прямо в Telegram с сохранением форматирования.
  * `👁 Исходник` — просмотр оригинального текста из канала-донора.
  * `🖼 Убрать / Вернуть медиа` — публикация с медиа или только текстом.
  * `❌ Отклонить` — удаление поста и очистка временных файлов.
* **Мгновенный тест:** кнопка `📥 Тест: спарсить свежий пост` у любого добавленного источника позволяет сразу протестировать связку, не дожидаясь выхода нового поста у донора.
* **Переключение режима:** можно в 1 клик переключаться между режимом **Предложки** и **Полным автопилотом** прямо в меню `/start`.

## 🚀 Пошаговая настройка (5 минут)

### Шаг 1. Получите ключи для чтения каналов (`TG_API_ID` и `TG_API_HASH`)
> 💡 **Рекомендация по безопасности:** для парсинга (Userbot) лучше использовать дополнительный аккаунт Telegram, а не ваш единственный основной, и не добавлять более 15–20 каналов за одну минуту.

1. Авторизуйтесь на официальном сайте Telegram: https://my.telegram.org
2. Перейдите в раздел **API development tools**.
3. Заполните форму (любое название `App title` и `Short name`, например `MyReaderApp`) и нажмите Create.
4. Скопируйте число `App api_id` (`TG_API_ID`) и строку `App api_hash` (`TG_API_HASH`).

### Шаг 2. Создайте бота управления (`BOT_TOKEN`)
1. Напишите в Telegram официальному [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Придумайте имя и `@username` боту и скопируйте выданный токен (`BOT_TOKEN`).
3. **Важно:** добавьте созданного бота в **Администраторы вашего целевого канала** с правом **Публикация сообщений (Post messages)**.
4. Узнайте свой личный числовой Telegram ID (напишите боту [@userinfobot](https://t.me/userinfobot)) — укажите его в `ADMIN_IDS`.

### Шаг 3. Получите API-ключ нейросети (`AI_API_KEY`)
Выберите любой удобный вариант:
* **Бесплатно (Google Gemini):** создайте ключ за 30 секунд в [Google AI Studio](https://aistudio.google.com/apikey) (`AI_PROVIDER=gemini`).
* **OpenRouter (доступ ко всем моделям, есть бесплатные):** https://openrouter.ai/keys (`AI_PROVIDER=openrouter`).
* **OpenAI:** https://platform.openai.com/api-keys (`AI_PROVIDER=openai`).
* **DeepSeek:** https://platform.deepseek.com/api_keys (`AI_PROVIDER=deepseek`).

### Шаг 4. Заполните файл `.env`
Скопируйте `.env.example` в `.env` и впишите полученные данные:

```env
TG_API_ID=12345678
TG_API_HASH=ваш_api_hash
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_числовой_telegram_id
TARGET_CHANNEL=@ваш_канал
AI_PROVIDER=gemini
AI_API_KEY=ваш_ключ_нейросети
```

## ▶️ Запуск

### Вариант А: На Windows (в 1 клик)
1. Убедитесь, что у вас установлен **Python 3.11 или 3.12** с официального сайта https://www.python.org/downloads/ (при установке обязательно поставьте галочку **`Add python.exe to PATH`**).
2. Запустите файл **`start.bat`**.
3. При самом первом запуске консоль попросит ввести номер телефона от аккаунта-парсера (в международном формате `+7...`) и код подтверждения из Telegram. После этого сессия сохранится в `data/sessions/` и больше спрашивать код не будет.
4. Откройте вашего бота в Telegram и отправьте команду `/start`!

### Вариант Б: На сервере / VPS через Docker (24/7)
```bash
cp .env.example .env
nano .env  # заполните ключи

# 1. Первый интерактивный запуск, чтобы один раз ввести код входа в Userbot:
docker compose run --rm autoposter

# Нажмите Ctrl+C после успешного входа и запустите в фоновом режиме 24/7:
docker compose up -d
```

## 📂 Структура проекта

```text
tg_ai_autoposter/
├── main.py               # Точка входа (запуск Userbot + Bot в едином цикле asyncio)
├── start.bat             # Автоустановка зависимостей и запуск под Windows
├── Dockerfile            # Контейнер для деплоя на VPS
├── docker-compose.yml    # Запуск 24/7 с автоперезапуском
├── requirements.txt      # Зависимости Python
├── .env.example          # Шаблон конфигурации
└── app/
    ├── config.py         # Конфигурация, валидация .env и базовый промпт редактора
    ├── database.py       # Асинхронная база SQLite (каналы, посты, настройки)
    ├── ai_service.py     # Работа с LLM, фильтр рекламы/дублей, очистка ссылок/@юзернеймов
    ├── userbot.py        # Telethon: подписка на открытые/закрытые каналы, сбор альбомов и медиа
    ├── publisher.py      # Отправка превью в предложку и публикация в целевой канал
    └── bot_handlers.py   # Меню администратора и кнопки модерации в Aiogram 3
```
